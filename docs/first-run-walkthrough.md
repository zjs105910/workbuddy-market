# 首次安装全流程实录（真实用户测试 · Windows 11 + WorkBuddy 桌面端）

> 本文记录 2026-10-12 一次完整的用户端实测：从零开始用 install.cmd 一键安装，
> 到网页市场可用、注册进 WorkBuddy 面板的全过程。所有输出均为真实运行记录，
> 不是合成演示。适合新用户对照自查，也作为验收基线。

## 一、下载与安全警告

1. 打开 README「一键安装」直链，浏览器立即下载 `install.cmd`（无跳转页面）；
2. 双击运行，Windows 弹出「无法验证发布者」——**预期行为**：脚本无付费数字签名
   （开源常规情况），点**运行(R)**；脚本为纯文本，可在仓库逐行核对。

## 二、安装器五个步骤（控制台输出解读）

| 步骤 | 输出 | 含义 |
| --- | --- | --- |
| [1/5] Python OK: py -3 | 已有 3.10+ 就跳过安装；没有则 winget 自动装 | 唯一的硬性依赖 |
| [2/5] pipx OK. | pipx 已装则跳过；没有则自动安装 + ensurepath | 隔离安装 CLI 用 |
| [3/5] CLI OK: …\workbuddy-market.exe | pipx 安装/升级 `workbuddy-market` 命令行 | doctor/verify 入口 |
| [4/5] Market root ready | 下载仓库 main.zip 解压到 `%USERPROFILE%\workbuddy-market` | 市场本体（网页+向导） |
| [5/5] Health check | doctor 体检后自动启动向导 | 见下节 |

> 已知边界（v2.32 实测）：网络直连 github.com 不稳定的环境，[4/5] 可能
> `curl (56) Recv failure`。安装器会先重试 3 次，再自动切换
> api.github.com 兜底通道；若仍失败，按提示手动下载解压即可。

## 三、doctor 体检项怎么读

向导启动**之前**跑的体检可能出现三个 ✗——它们都会在向导运行后自动消失，
不是故障：

- ✗ 配置（market.config.json）：首次安装本来就没有，向导会从模板初始化；
- ✗ 运行状态目录（STATE_HOME）：首次启动后才创建；
- ! 社区注册表缓存：首次联网刷新后生成。

体检为「用户了解环境」服务，不是拦截——真正的前置检查在向导选择注册后才做。

## 四、首次启动向导

```
首次启动：选择本次的启动方式
1) 只浏览市场（默认；回车即选这个，不改动 WorkBuddy 配置）
2) 注册到 WorkBuddy（写 known_marketplaces.json，仍需通过打包/自检前置检查）
```

- **回车（1）**：只起网页，注册表零改动，随时可以反悔；
- **输入 2**：注册市场进 WorkBuddy 插件面板。注册前仍会跑打包与自检
  （[1/4]~[2/4]），不过就拒绝写入。

实测选择 2 后的四步：打包本机 skill（增量同步）→ 自检四层一致 →
写 known_marketplaces.json（自动备份旧文件到状态目录 backups/）→ 起服务
`http://127.0.0.1:8777/`。

## 五、网页市场三个标签页

- **本机技能**：只显示**已收录进市场**（market.config.json 的 localPlugins）
  的插件。新装市场这里是空的——**这不代表你的 skills 消失了**，见第六节。
- **精选市场**：50 条人工审核收录的社区目录（每日 CI 刷新），
  支持收藏/详情/一键安装（固定产物按 sourceCommit 固定来源）。
- **探索 GitHub**：全网搜索 + 收录源。全网搜索默认返回 8 条
  （`SEARCH_LIMIT_DEFAULT=8`，后端参数上限 20），按更新时间排序，
  确认来源后可一键安装。

## 六、「我的本地技能去哪了？」

**没有消失，一个都没动。** 首次启动向导发现本机 33 个 skills 时只做摘要、
**绝不自动收录**（安全设计：收录哪些进市场由你决定，避免把私人技能意外
打包分发）。让技能出现在「本机技能」标签页的方法：

1. 编辑市场根的 `market.config.json`，往 `localPlugins` 数组加条目
   （照抄已有条目的结构，name 填 skills 目录里的文件夹名）：

   ```json
   "localPlugins": [
     {
       "name": "browser-cdp",
       "version": "1.0.0",
       "displayName": "浏览器自动化",
       "category": "自动化",
       "description": "通过 CDP 驱动真实 Chrome…"
     }
   ]
   ```

2. 保存后在网页右上角点**重新打包**，本机技能页就会出现它们。

## 七、卸载与恢复

- 撤销 WorkBuddy 注册：市场根目录的 `撤销注册.cmd`，或网页右上角「撤销注册」
  （只删注册条目，不动已装技能）；
- 卸载已安装的某个技能：网页里对该插件操作（走所有权检查 + 回收站）；
- 彻底移除：pipx uninstall workbuddy-market + 删市场根目录 +
  删 known_marketplaces.json 里对应条目。
