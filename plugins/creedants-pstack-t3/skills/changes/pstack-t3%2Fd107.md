- `python3 scripts/sync_upstream.py --check` reports what upstream changed since the pinned commit and changes nothing in the checkout. It reads upstream at `--ref` from a clone in a temporary directory. It prints `up to date (<commit>)` when upstream is at the pinned commit. Otherwise it prints the new commit and one row for each changed, added, or removed path under `pstack/`. Each row says what pstack-t3 does with that path today, which is `overridden by <file under t3/>`, `dropped by t3/removed.txt`, `ships unchanged`, or `not shipped`. Both cases exit 0. `--json` prints the same report as one JSON object. `--repository` reads another upstream. Both flags need `--check`. A git or network failure exits 1 with git's error.
