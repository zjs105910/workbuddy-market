- `brigade.py ticket add --from-report reports/D2.md` files one waiting ticket for each follow-up in a worker's item report, with source `report` and a ref such as `perf/reports/D2.md#3`. It reads list items and paragraphs. It prints, and does not file, a paragraph that introduces a list, a paragraph after a section's last list item, and a block whose whole text is `None`, `None required`, `None needed`, `Nothing`, `Nothing needed`, `N/A`, `Not applicable`, or `No follow-ups`. It files every longer block, so a statement such as `No README edit is needed.` becomes a ticket for the coordinator to drop. It skips a follow-up whose text a ticket in any state already holds, so a second run on the same report adds nothing. It refuses a path with a `..` component, a report that is a symbolic link, and a report that resolves outside the store's `reports/`. A run changes only the ticket table, the log, and `lastActivityAt`. `--dry-run` prints what a run would add and changes no table and no log. Each worker brief now asks for a `## Follow-ups` section with one top-level list item per follow-up, and the brigade skill tells the coordinator to run the command after a passing review.
