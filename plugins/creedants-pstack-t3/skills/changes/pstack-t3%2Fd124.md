- `doctor` now prints two or more findings under one harness that have the same advice as one group. The group is a line with their count and the advice, then one line per record. A finding alone in its advice still prints as one sentence.
- `doctor`'s line for the owner file of a checkout whose directory is missing now also says that deleting the file removes that checkout's claims and removes no link they name and no row of `install-manifest.json`.
- `doctor` now exits 1 when it cannot read or use `install-manifest.json` or this checkout's owner file, the two files that stop `install` and `uninstall`. It names each of the two it could not use and still runs the checks that do not need that file.
- An install that made a `backups/<stamp>` directory now removes, when its steps end, each `<harness>` directory it made there if that is empty, then the `<stamp>` directory if that is empty. It removes nothing through a symlink at `backups/`, `<stamp>`, or `<harness>`. It skips a move whose `<harness>` directory was already in its new `<stamp>`.
