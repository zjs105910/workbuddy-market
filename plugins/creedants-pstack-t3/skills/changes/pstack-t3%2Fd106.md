- `docs/cli/` is a new command-line reference, one generated page each for `brigade.py`, `land.py`, and `roles.py`, plus an index at `docs/cli/README.md`. `python3 scripts/build.py` generates the pages from each script's argparse definition, with every command, flag, choice, and default. A change to one script changes only that script's page, and a renamed flag fails the tests until the build is rerun.
