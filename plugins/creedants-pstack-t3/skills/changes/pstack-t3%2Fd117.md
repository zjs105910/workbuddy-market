- roles: `roles.py` has one definition of a model's family, the leading word of the normalized model id. A provider path or a Bedrock prefix no longer makes a second family in the default `verifiers` panel, the built-in seat picker, the exact-model tie-break, or the `--launches-seats` pool, so the default `verifiers` panel seats one of `opencode/muse-lite-2-free` and a bare `muse-lite-2`, and a built-in seat with no exact `grok-4.7` picks `x-ai/grok-4.8` as a `missing model`.
- roles: `show` and `validate` drop the `review backups` seats that `backup` drops when no provider is out and no author is named: a Codex or Cursor seat, a seat whose provider is not runnable or whose model is not in the catalog, and a repeated family. With a catalog, `show` prints the kept seats and a note with the reason for each dropped seat, and it prints no `inherit` or substituted model for this role. Without a catalog it prints `catalog-required`. `validate` prints each dropped seat as a problem and exits 1, so `write` refuses it without `--force`. A `review backups` role whose every seat is a fast Grok or Claude Haiku 4.5 seat no longer prints `unset` in `show`. It prints the config file as its source and the `skipped configured seat` notes, with `"seats": []` with a catalog and `catalog-required` without one.
- roles: the `has no seat` error names only the excluded kinds among the models it lists. For `show --launches-seats` it names the runnable providers of the launch pool, or says that none of the pool's providers can run child tasks.
