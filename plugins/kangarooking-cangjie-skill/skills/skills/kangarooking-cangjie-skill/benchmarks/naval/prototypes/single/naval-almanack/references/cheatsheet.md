# 决策规则速查 — 《纳瓦尔宝典：财富与幸福指南》

| 能力 | 一句话规则 |
|---|---|
| 财富结构：责任+产权+杠杆+避免出局 | 先诊断收入结构：有无产权、用了几种杠杆、下行风险会不会让你出局。 |
| 特殊知识发现与产品化定位 | 找到「对你像玩、对别人像工作」的特殊知识，再用代码/媒体杠杆规模化。 |
| 决策启发式：无法决定就答否 | 无法决定就答否；三个重大决定值得花一两年；两条均等的路选短期更痛苦的。 |
| 高时薪时间分配与外包判据 | 给自己定离谱高的时薪，低于时薪的事外包或不做；不随收入升级生活方式。 |
| 阅读元技能：读什么与怎么读 | 读你所爱直到爱上阅读；原著与经典优先；没有读完义务；以教促学。 |
| 屏幕戒断与多巴胺管理 | 屏幕活动是用长期后果换短期快感的多巴胺零食；用习惯替换五步戒断。 |
| 判断力训练：方向>努力、心智模型库 | 判断力（知道行为的长期后果）比努力重要；从基础学科重建推理，收集心智模型。 |
| 复利与长期游戏 | 财富、知识、声誉、关系都遵循复利；只玩长期正和游戏。 |
| 委托-代理识别 | 看收益与创造价值绑定多紧——绑得紧像委托人把事做好，松则像代理人为自己优化。 |
| 幸福是可训练的技能 | 幸福=缺憾感清空的默认状态；欲望是与自己的契约，同时只留一个重大欲望。 |
| 游戏选择：地位游戏 vs 财富游戏 vs 单人游戏 | 识别自己在玩哪种游戏；躲开零和地位游戏，回到内在记分卡。 |
| 情境三选项：改变/接受/离开 | 任何处境只有三选项——改变它/接受它/离开它；三者都不做是痛苦之源。 |
| 期望边界、愤怒解体与就业自由 | 期望不是合同（约定才是）；愤怒是自我惩罚；低生活成本买来就业自由。 |
| 心猴关停与冥想 | 内心独白是失控程序不是「我」；用调试模式逐条观察念头，意识到即失去控制。 |
| 五只黑猩猩：主动选择同伴 | 你的行为由最常接触的五个人预测；同伴是主动选择而非巧合。 |
| 身份清空与自我形象杠杆 | 放下身份才能看清真相；更新自我形象才能替代自律。 |
| 彻底诚实与反馈技术 | 所想与所说一致；具体表扬、一般批评；秘密越少快乐越多。 |
| 理性佛学：验证一切 | 亲自测试一切、保留有用的；不可证伪的主张不进入基本真理。 |
| 生命意义三答案 | 意义=个人创造+愿意为之受苦；拥抱死亡是意义的入口。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
