# @shadowclone/cloud

Sets up the GitHub bot, writes its workflows, exports reviewed guidance, and reports its status. The web wizard and the MCP server call it.

## Owns

- `src/setup/`: account and App setup, environment, ruleset, and checklist (`setUpAccountClone`, `activateClone`, `readCloudChecklist`).
- `src/workflow.ts`, `workerWorkflow.ts`, and `reviewJobs.ts`: the generated GitHub workflows.
- `src/guard/` and `react.ts`: the code that runs inside the workflows to validate events.
- `src/export.ts` and `deliveryFiles.ts`: `exportGuidance` and `writeDeliveryFiles`.
- `src/status.ts`: `cloneStatus` and `readInstallation`.

## Rules

- Secrets reach GitHub only through the standard input of `gh secret set`. Workflows name a secret and never hold its value.
- Setup refuses a `shadowclone` environment that allows a branch other than the default branch.
- `exportGuidance` refuses an unknown or blocked repository origin. It requires the `shadowclone-work` skill.
- Files in `src/guard/` and `react.ts` run inside the generated workflow. They import only each other and types.
- The guard checks the live entity, the pause label, and the run budget before a worker starts.

## Tests

Run `bun test` in this folder, or `bun test packages/cloud` from the root. The `./testing` export gives `guidanceFixture`, `setupRepository`, and `syntheticApp`. The tests use a fake `gh` and need no account.
