## Owns

- `src/apply.ts`: `commitLocalChanges`, `revisionTarget`, and the apply and reverse logic.
- `src/store.ts`: revision records in `history/`, with `listRevisions` and `readRevision`.
- `src/index.ts`: `showRevision`, which returns the redacted revision text.
- `src/types.ts`: `LocalRevision` and `FileUpdate`.

## Rules

- A revision records the text of each file before and after the change.
- `commitLocalChanges` saves the revision as `prepared` before it writes any file. It saves `applied` after the last write.
- If a file changed after the caller read it, the commit fails and keeps every file.
- If a write fails, the package restores the files that it already wrote.
- A target outside the revision root is an error. A revision has at most 256 files and no duplicate destination.
- The history files use owner-only permissions.
