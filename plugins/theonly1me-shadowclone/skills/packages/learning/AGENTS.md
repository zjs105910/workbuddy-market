# @shadowclone/learning

Turns evidence from consented sessions into guidance. It distills, reconciles, and queues rules for review. It also runs the background worker and `remember`.

## Owns

- `src/distill/`: evidence selection (`authorizedLearningEvents`, `materializeEvidence`), reconciliation, consolidation, and checkpoints.
- `src/learning/`: `runLearningService`, `runAutomaticLearning`, `scheduleLearning`, the pending queue, receipts, and probes.
- `src/learning/skillMaintenance/`: skill proposals and conflict review (`maintainSkills`).
- `src/preferences/`: `rememberPreference`. `src/importRules/`: repository guidance import.

## Rules

- Only user prompts, plan decisions, question answers, permission denials, and interruptions with a text reference are evidence.
- Each reference passes `authorizeRef` for the current consent and `resolveRedacted` before the model sees it.
- All model calls for one learning run share one `createLearningExecution`. Do not start a second budget.
- A learned rule that reads like an instruction to the agent stays pending with its reasons (`heldLearningReason`).
- The background worker takes the `learning-worker.db` lock. It exits as `busy` when another worker runs.
- Background learning needs `distillation.deep`, `distillation.automatic`, and a managed policy that allows it.

## Tests

Run `bun test` in this folder, or `bun test packages/learning` from the root. The `./testing` export gives `conflictFixture` and `preferenceEditFixture`. The tests use mock runners, so they make no model call.
