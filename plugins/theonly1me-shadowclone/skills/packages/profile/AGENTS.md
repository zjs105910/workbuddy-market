## Owns

- `src/profile/`: rule parsing and rendering, evidence, `compileProfile`, `writeLegacyProfile`, and repair plans.
- `src/references/`: scoped reference records, with `readScopedReferences`, `searchReferences`, and `recallReferences`.
- `src/migrate/claudeMemory/`: `scanClaudeMemory`, `createClaudeMemoryMigrationPlan`, and `migrateClaudeMemory`.

## Rules

- A rule that the model infers needs three independent sessions (`independentSessionThreshold`). Explicit evidence can activate after one.
- References read through `resolveRedacted`, so recall returns redacted text.
- The profile compiler has a byte budget (`defaultProfileByteBudget`, `defaultIndexByteBudget`). It lists omitted rules.
- `writeLegacyProfile` takes a lock and writes through `commitLocalChanges`, so `undo` can reverse it.
- A reference file is at most 64 KiB. A memory scan reads at most 256 files and 2 MiB.
- This package keeps the legacy profile only. Active skill delivery lives in `environment`.
