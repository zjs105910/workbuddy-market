For each implementation, answer true or false for each claim. Judge only what is in the code you see.

1. Every function, class and variable name says what it does or holds.
2. No function is longer than 25 lines.
3. Each function works at one level of abstraction.
4. Business rules appear as named functions or named constants, not as inline arithmetic.
5. No control flow is nested deeper than two levels.
6. No logic is duplicated.
7. Each module has one clear purpose that its name states.
8. Data flow is explicit. State changes happen in few, obvious places.
9. Edge cases are handled in named steps, not scattered conditionals.
10. There is no dead code and no unused parameter.
