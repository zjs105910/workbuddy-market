# EP002 十块钱回来了

## EP002-SC001 内外 · 安和面馆门口 · 黄昏

梁锋把一张皱折的十元纸币压在柜台上。陈予安看了一眼，没有伸手。

梁锋：上次那碗面，我来还钱。

陈予安：你要还的不是我。

梁锋打开配送箱，里面多放着一把折伞。

梁锋：昨晚一个新骑手摔了车。我替他付了饭钱，还把伞给了他。可这十块钱，我还是想让你收下。

陈予安把纸币推回去，翻到梁锋那一页，用铅笔划掉“待传”。

[画面文字] 账本记录：梁锋／一碗面／已传一次。

陈予安：这才叫还清。钱留着，下一次别让人淋着。

梁锋收起纸币，第一次坐到柜台里侧帮陈予安叠毛巾。

[连续性] 十元纸币仍由梁锋持有；梁锋的账本状态改为“已传一次”。
