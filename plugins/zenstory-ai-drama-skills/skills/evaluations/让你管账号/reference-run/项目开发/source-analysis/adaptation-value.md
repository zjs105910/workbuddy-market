# 改编价值与分集候选

## 零、S1 快评的回填对照

S1 是抽样 12 章（覆盖率 0.6）得出的假设。全量拆解 20 章 / 437 个情节点之后，逐条对照：

| S1 的判断 | 全量结果 | 结论 |
|---|---|---|
| 框架是升级流 + 弱复仇线 | 成立。两次任务闭环，第 13–17 章的对手线不驱动主线 | **未推翻** |
| `screen_ready` 约 67% | 全量 24 个候选集里 19 个 `screen_ready`（79%），5 个 `needs_carrier`，`prose_only` 0 个 | **被推翻（偏保守）**。原因见下 |
| 第 13 章是 `prose_only` | 全量看不成立。第 13 章的功能（对手登场并制造指控）完全可以由剪辑台前的一个人承担；抽样时把「大段网友评论」误当成了功能本身，其实那只是原著的载体 | **被推翻** |
| 建议从第 1 章原点开篇 | 成立 | **未推翻** |
| 制作负担中等偏高，集中在军事大场面与老年/年代感 | 成立，且更精确：负担集中在第 2、10、18、19、22 集 | **未推翻，已细化** |
| 三处风险：世界设定被压掉、能力误认、老兵线断裂 | 全部成立，且第三条比抽样时看到的更严重 | **未推翻，加重** |
| 分集量级 22–26 | 实际切出 24 | **未推翻** |

**被推翻的那两条有同一个成因**：抽样阶段容易把「原著用什么写」当成「这个功能能不能拍」。
第 13 章满屏都是网友评论，看上去无法影像化，但它承担的功能是对手登场，那完全是可见行动。
下一本书的快评应当先问功能，再看载体。

## 一、三类判定（全量）

| 判定 | 候选集数 | 占比 |
|---|---|---|
| `screen_ready` | 19 | 79% |
| `needs_carrier` | 5 | 21% |
| `prose_only` | 0 | 0% |

5 个 `needs_carrier` 全部指向同一类载体：**系统播报与不出声的内心判断**。

| 候选集 | 文字专属的载体 | 建议的新载体 |
|---|---|---|
| EP01 | 系统绑定与任务播报 | 手机屏幕上的账号后台与倒计时条 |
| EP05 | 三段市井场景的旁观叙述 | 三个几乎无台词的可见场景 |
| EP08 | 爷爷独自的判断 | 三个递进的微动作 + 一句短评，意图靠后续事件回溯 |
| EP09 | 大段网友评论与公告全文 | 两位团领导的一场对话 + 一条可读公告 |
| EP12 | 国运的四条加成播报 | 可读的系统提示层 + 两条微博数据的并置 |

没有 `prose_only`：本书没有依赖叙述性诡计或长铺垫的段落，
唯一接近的是国运设定，而它可以被压成一条可读提示。

## 二、制作负担落在哪里

| 负担类型 | 集中在 | 说明 |
|---|---|---|
| 军事大场面（导弹齐射、火箭炮实弹、装甲车、方阵） | EP02、EP04、EP10 | 全部生成，观众辨识度高，露怯代价大。建议远景 + 烟尘遮挡 + 快切，把震撼交给声音与人物反应 |
| 年代感与老年表演（百岁老兵、战场闪回、泛黄照片） | EP18、EP19、EP23、EP24 | 靠手部、勋章、旧照片、军旗承担，避免全身年轻化穿帮 |
| 人群（军营集体敬礼、操场数百学生鞠躬） | EP21、EP22 | 建议前排特写 + 后排虚焦 + 声音承担规模 |
| 可读文字（账号数据、官方公告、微博点赞数、诗） | EP01、EP03、EP09、EP10、EP12、EP20 | 数字与文案本身是剧情论据，必须可读，需与美术确认字号 |
| 虚构场景（悬崖对话） | EP19 | 全剧唯一，需与现实段落明确区分 |

日常场景（办公室、工位、剪辑室、居室、出租屋）负担很低，且高度可复用。

## 三、必须由创作者裁定的三件事

这三件在本层只列出，不做决定。

1. **世界设定 W2 的存续**。「这个世界的新媒体整体没起来」是全书难度的地基，
   但它在原著里只在第 1–2 章成立过两次，此后再无加强。
   按篇幅比例改编，它几乎必然被压掉；压掉之后，五天一百万粉就失去了刻度。
2. **能力误认是否产生代价**。歌与伴奏来自系统，全书所有人当成他的原创，
   而原著从未澄清、也从未让这层误认付出任何代价。系统同样没有失效条件。
   竖屏短剧里一个没有反向压力的金手指，会让每一集的紧张感失去支点。
3. **李林这条线的断裂**。他在 EP03–EP04 承担了全书最重的一次情感建立，
   第 10 章后消失，第 11 章起换成一批全新老兵。照搬这个断裂，
   EP04 埋下的情感投资在 EP23–EP24 收不回来。

## 四、分集候选

24 个候选，见 `episode-candidates.jsonl`。切分依据是**一次局部戏剧结果的闭合**，
不按章号或字数平均切：第 10 章切成两集（实弹认知冲击 / 专业团队对照是两个结果），
第 15、16、18 章各切成两集，第 20 章单独成集。20 章全部被覆盖，无空转章。

每条候选带 `source_ref` / `index_ref` / `chapter_range` 指回索引，可核查、可反驳。
`creator_acceptance` 一律 `pending`——**本技能不批准自己的产物**。
