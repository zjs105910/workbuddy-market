# 第 10 章 · 专业团队拍得还不如他拍的好？

## 概要

这一章给出全书关于什么是好内容的答案。主角第一次站到实弹训练现场，才意识到之前拍摄并没有用实弹，他那时全部心思都在运镜上。他把这份震动写成一首咏剑的旧诗发了出去。与此同时，领导们决定请专业团队重拍正式版宣传片，两天后成片放完，屋里陷入沉默——画质更好、构图更专业，却少了灵魂。团长拍板用原版。读完这章，主角的能力得到了最强的一次证明。
