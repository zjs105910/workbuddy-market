# 第 4 章 · 向前进！ 向前进！

## 概要

视频看完了，反对全部收回。本章把群体的翻转和一个人的私人记忆并置：所有人都在喊牛逼时，李林独自把视频重看了一遍，歌声把他带回高原、带回边境冲突、带回那个替他挡子弹的战友国强。这一章给全书装上情感底座——它让爆火不只是数据，而是有人被真正击中。读完这章，李林从一个网友变成全书的情感落点。
