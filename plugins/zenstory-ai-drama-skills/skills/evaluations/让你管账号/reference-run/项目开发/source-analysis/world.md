## 一、世界的基本前提

| ID | 设定 | 出处 | 地位 |
|---|---|---|---|
| W1 | 平行世界，与原世界几乎一模一样 | 第 1 章 | 背景 |
| W2 | **这个世界的新媒体整体极不发达**：不只军队，民间粉丝过万的博主都屈指可数，全行业人气不如主角前世刚起步时 | 第 1 章 | **全书难度的地基** |
| W3 | 火箭军新媒体接近空白：十几个账号粉丝总数加起来还没有账号数量多（微博 2 / 破站 1 / 短视频 0 / 公众号 1 / 文工团公众号 0） | 第 1 章 | 起点的量化 |

| W5 | 平台叫抖手，是后起之秀；主角判断它贴近现实、深入普通人生活，是爆款风口 | 第 2 章 | 载体选择的依据 |
| W6 | 军内背景：文宣工作常年垫底，年中军宣会被其他军团调侃，前两天内部会被点名批评；马上年中总结要评比，关系单位荣誉与个人晋升 | 第 2、6 章 | 机构动机 |
| W7 | 外部背景：西方最近不安分，军方高层认为是时候展示硬实力 | 第 8、9 章 | 官方推动力的真实来源 |

> **W2 必须保留**。没有它，五天一百万粉既不可能也不惊人，主角的前世经验也不构成降维打击。
> 压缩可以；删掉或改成「这个世界短视频很发达」，主角的成功就失去了刻度。
> 注意 W2 在原著里只在第 1–2 章成立过两次，此后再无加强（见 `rhythm-and-emotion.md`）。

## 二、力量体系：文娱国运系统

| 规则 | 内容 | 出处 |
|---|---|---|
| 触发 | 在主角产生明确需求（为 BGM 发愁）时唤醒并绑定 | 第 1 章 |
| 授予形式 | 一次性赠予具体能力与成品素材：天王级唱功、大师级导演能力、《中国军魂》伴奏 | 第 1 章 |
| 任务机制 | 发布带硬指标与死线的任务，并持续播报剩余量与倒计时 | 第 1、5、8 章 |

| 国运 | 提升后为科技、文化、军事各领域带来气运加成，表现为具体条目播报（航母研发缩短五年、芯片人才发掘效率提升、大学学科排名提升、军人训练效果增加） | 第 11 章 |
| 失效条件 | **原文未明确**。全书未出现任何任务失败的后果，也未说明能力会不会被收回 | — |
| 代价 | **原文未明确**。系统给的东西被所有人当成主角自己的才华（第 7 章），但这层误认从未产生任何后果 | — |

**两处空白是改编时必须自己补的**：失效条件与使用代价。原著把系统写成纯增益，
没有反向压力；竖屏短剧里，一个没有代价的金手指会让每一集的紧张感失去支点。
