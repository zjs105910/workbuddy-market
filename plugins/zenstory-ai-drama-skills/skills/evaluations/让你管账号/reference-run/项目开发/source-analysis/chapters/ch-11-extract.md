# 第 11 章 · 新任务：老兵的愿望

## 概要

第一个任务闭环：粉丝破百万，系统结算奖励并第一次解释国运是什么。紧接着第二个题目从一次闲聊里长出来——记者说报社的老兵慰问稿反响平平、评论区几乎没有人。主角把两条数据一对比，决定自己来试。系统随即发布新任务。读完这章，驱动力从完成指标转向他自己想做这件事。
