# 第 13 章 · 争议

## 概要

预告成为攻击面。粉丝一片期待中夹进质疑的声音，而一个靠制造争议吃饭的自媒体博主嗅到了机会，把预告剪成消费老兵的指控投向流量高峰。副团长看到预告后也开始担心舆论风险，却被日常工作打断。读完这章，对手正式登场，而主角对这一切一无所知。
