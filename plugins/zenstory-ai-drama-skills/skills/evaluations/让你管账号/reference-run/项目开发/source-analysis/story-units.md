# 剧情单元

聚合自 `chapters/ch-1..20-extract.md`，不回头重读原文。
故事框架：**升级流 + 一条弱复仇线**（S1 判定，全量结果未推翻）。

## 阈值自检

| 指标 | 目标 | 实测 | 判定 |
|---|---|---|---|
| 归属置信 | ≥ 0.85 | **1.00**（437/437 个情节点有明确单元归属） | 通过，无「待复核」单元 |
| 覆盖率 | 85%–95% | **100%**（437/437 已归类） | 触发上界，说明见下 |
| 重叠率 | ≤ 35% | **0%**（无跨单元共享情节点） | 通过 |

**覆盖率 100% 触发上界的说明**：本材料 20 章、单主线连续叙事、严格时序推进，
适用「小体量素材的例外」——按时序切分时覆盖率天然接近 100%，不是过度归并的信号。
反证是重叠率为 0：如果存在过度归并，相邻单元会开始共享情节点。
未为凑阈值人为拆分或合并任何单元。

## 单元密度的不均衡（供 S5 使用）

U03、U04 各 18–21 个情节点却各自完成一次完整翻转，密度最高；
U06、U07、U09、U12 各含两章、44–50 个情节点，内部实际包含两次结果，切集时应各拆为 2 集。
U14 只有 12 个情节点，是全书最短的单元，但它承担收束，不能与 U13 合并。
