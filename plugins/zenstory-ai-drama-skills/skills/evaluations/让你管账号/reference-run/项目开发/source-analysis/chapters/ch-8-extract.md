# 第 8 章 · 钟嘉嘉的请求

## 概要

两条线在这一章交叉：主角的账号继续涨到二十万，而记者把视频带回了家。她的爷爷是从战场上下来、多年位居高位的老人，看完视频只说了两句短评，却在孙女回房后独自想到了另一件事——西方最近不安分，是时候让人看看硬实力。读完这章，一支短视频的意义从流量变成了对外姿态，推动它的力量第一次来自体制的最高处。
