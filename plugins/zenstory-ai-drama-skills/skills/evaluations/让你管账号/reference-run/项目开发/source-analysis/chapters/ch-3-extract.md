# 第 3 章 · 这个拍 MV 的人，简直太懂！

## 概要

反对声先升到顶点：举报、差评、约着去冲账号逼平台封号。然后一个人把它拦住了——退伍老兵李林没有讲道理，只问了一句你们看过没有，甩出链接。本章的全部作用是把所有反对者按到屏幕前，让他们自己去看。读完这章，冲突从立场之争变成事实检验，视频本身成为唯一裁判。
