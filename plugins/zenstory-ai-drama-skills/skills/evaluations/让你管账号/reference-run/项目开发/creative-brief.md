## 二、戏剧承诺

一个带着上一世全部经验的人，掉进一个还没有人会用这套经验的世界。
他要证明的不是自己有多强，而是**这份被误认成天赋的东西，配不配得上人们给他的信任**。

## 三、观众反复能获得的回报

| 回报 | 形式 |
|---|---|
| 降维打击的爽感 | 他用所有人都有的工具（一部手机）做出所有人都做不到的东西 |
| 先抑后扬 | 每一次作品出场前，都先有一群人认定它不行 |
| 被看见 | 一个被忽略的人或群体，因为他的作品第一次被大量的人认真注视 |

## 四、目标观众与情绪落点

军旅、主旋律、系统流的交叉受众。情绪落点不是"他赢了"，是"有人终于被看见了"。

## 五、制作边界

- 军事大场面全部生成，远景加烟尘遮挡，不给单发弹体长镜头。
- 使用架空番号与非写实徽记，不出现可辨识的真实单位标识。
- 老年角色靠手部、旧物、勋章承担年代感，避免全身穿帮。
