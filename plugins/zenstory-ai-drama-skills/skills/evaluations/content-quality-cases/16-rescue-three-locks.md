# 三道锁扣

- 类型：工业救援
- 目标时长：75–100 秒
- 角色：卡在检修平台外侧的风机技师陆遥；隔着防火门操作绞盘的同伴范岭
- 场景：山地风机塔筒中段，雷雨将至
- 已知事实：四十五秒后系统会为防雷自动收紧牵引绳；陆遥必须在收紧前依次完成三道安全锁扣，完成的标准是锁舌闭合、受力环归位并由她拉拽确认。第一道可直接扣，第二道的织带被护栏压住，第三道在她身后。范岭能放松绞盘一次、持续八秒，但看不见陆遥身后的锁扣，也不能关闭自动收紧。
- 本集承诺：让观众能核对三道锁扣各自的完成或失败状态，并在字面死线内看到一次基于现有装备和两人协作的换策及结果。
- 必须保留：报时单调递减；“开始扣”“请求松绳”或喊出编号都不等于某道锁扣完成；范岭不能突然获得新权限或替陆遥完成看不见的动作；部分完成或失败可以成立。
- 输出：只写完整单集 Markdown 剧本，不解释创作过程。
